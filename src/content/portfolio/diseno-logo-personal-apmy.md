# El logo de APMY

Partí de una fotografía de Wood Teardrop.

Para crear el logo de APMY combiné una fotografía de Wood Teardrop con la imagen de un escudo que tomé como base. Edité la composición y la publiqué en febrero de 2019.

Es el logo que encabeza la web actual de apmy.es.
